# جیم باس 💪 (Gym Boss)

بازی کلیکری/تدرجی باشگاه و بدنسازی — نسخه وب، کاملاً آفلاین، بدون نیاز به نصب.

## اجرا
روی فایل `index.html` دابل‌کلیک کن تا توی مرورگر باز شود. همین! (کروم/اج/فایرفاکس)

## روش بازی
- **کلیک روی زمین بازی** (یا کلید `Space`) = یک حرکت وزنه زدن → سکه و تجربه می‌گیری.
- کلیک‌های پشت‌سرهم **کمبو** می‌سازند و درآمد هر ضربه را تا ×۲ زیاد می‌کنند.
- از **فروشگاه** تجهیزات بخر: دمبل، هالتر، کتل‌بل، دستگاه بدنسازی (قدرت ضربه)، مربی شخصی (درآمد خودکار حتی وقتی بازی را بستی)، پروتئین (ضریب کل درآمد).
- هرچه سطح بگیری، **عضله‌های کاراکتر بزرگ‌تر** می‌شوند و لقب جدید می‌گیری (تازه‌کار → جیم باس).
- دکمه **🥊 مبارزه با باس**: ۱۵ ثانیه وقت داری تا جان باس را صفر کنی. برد = جایزه بزرگ سکه + رفتن به سطح باس بعدی.
- **پروتئین طلایی** ✨ هر از گاهی از صفحه رد می‌شود — بگیرش تا ۳۰ ثانیه بوست ×۲ بگیری.
- بازی به‌طور خودکار در مرورگر ذخیره می‌شود (localStorage). دکمه «شروع دوباره» پیشرفت را پاک می‌کند.

## نکات فنی
- فقط HTML/CSS/JS خالص، بدون هیچ کتابخانه یا اینترنت اجباری (فونت وزیرمتن آنلاین است و در نبودش از Tahoma استفاده می‌شود).
- صداها با Web Audio API ساخته می‌شوند؛ با دکمه 🔊 قطع/وصل می‌شود.
- ایده‌های مرحله بعد: تبدیل به اپ اندروید/iOS با Capacitor یا WebView، جدول امتیازات آنلاین، پیشرفت (Prestige)، آیتم‌های محدود زمانی.
